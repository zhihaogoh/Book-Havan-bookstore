# 📚 Bookstore E-Commerce Frontend

A responsive bookstore e-commerce frontend built with React.

This project was created to practice frontend development skills, including
React components, routing, responsive design, product listing, shopping cart,
and checkout flow.

## 🚀 Features

- Home page
- Book categories
- Product listing
- Product details
- Shopping cart
- Checkout process
  - Shipping
  - Payment
  - Review
- User profile
- Responsive design for desktop and mobile

## 🛠 Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- React Bootstrap
- React Router

## 📂 Project Structure

src/
├── components/
├── pages/
├── assets/
├── App.jsx
└── main.jsx

## 💻 Installation

Clone the project:

git clone YOUR_GITHUB_REPOSITORY_URL

Go to the project folder:

cd bookstore

Install dependencies:

npm install

Start the development server:

npm run dev

## 📱 Responsive Design

The website is designed to support:

- Desktop
- Tablet
- Mobile

React Bootstrap grid system is used for responsive layouts.
